
# Multimodal Forgery Detection in Identity Documents

## Project Overview

An AI-based identity verification system developed as a Final Year Project at the Pakistan Institute of Engineering and Applied Sciences (PIEAS), Islamabad.

The project focuses on exploring AI driven approaches to identity document verification and forgery detection.

## Project Information

- **Project Type:** Final Year Project (FYP)
- **Domain:** Artificial Intelligence / Machine Learning
- **Institution:** PIEAS, Islamabad, Pakistan
- **Status:** Patent Pending

## Project Highlights

- AI-based identity verification system.
- Research and development in identity document forgery detection.
- Development of a functional application.
- Experimental evaluation and testing.
